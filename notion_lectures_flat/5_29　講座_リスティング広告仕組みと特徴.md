# リスティング広告仕組みと特徴

## 1. 広告の全体像

まず広告には、テレビ・ラジオ・新聞・街頭・雑誌・デジタルがあります 。

テレビは幅広い世代に届き、ラジオは音声のみでキャッチーさが重要、新聞は信頼性と地域指定、街頭はエリア指定、雑誌は読者属性が読み取りやすい、デジタルはニーズのある人に絞って出せる、という整理でした 。

そのうえで、デジタル広告の中にさらに種類があり、リスティング広告、ディスプレイ広告、動画広告、SNS広告、ネイティブ広告、アフィリエイト広告の6つに分かれます 。

この「まず広告全体 → 次にデジタル広告 → さらに個別手法」という階層が、PDFの最初の大事な流れです 。

## 2. デジタル広告の特徴

デジタル広告は、マスメディアよりもターゲティング精度が高いのが特徴です 。

年齢、性別、興味関心、Web上の行動履歴などで配信対象を絞れ、しかも表示回数・クリック数・費用をリアルタイムで検証できます 。

予算配分や掲載スケジュールも柔軟に変えられるので、改善しながら使う広告です 。

日本の広告費でも、2022年のインターネット広告費は30,912億円で、テレビ広告費の18,019億円を上回っていました 。

## 3. Google広告の考え方

Google広告の根っこには、「世界中の情報を整理し、世界中の人々がアクセスできて使えるようにする」という理念があります 。

その考え方を実務に落とすと、マイクロモーメント、つまり「何かしたい瞬間にスマホで検索する行動」を捉えることになります 。

生活者は1日にスマホを150回チェックし、調べ物の最初にモバイルを使う人が60%、モバイル検索結果を購買判断に使う人が87%でした 。

Googleは検索、YouTube、Googleマップ、Gmail、Chrome、Androidなどのデータを横断し、10億超のユーザー情報と機械学習で広告精度を高めています 。

## 4. リスティング広告の仕組み

リスティング広告は、検索キーワードに反応して表示される検索連動型広告です 。

広告主がキーワードと広告文を設定し、ユーザーが検索した瞬間にオークションが起きて、掲載順位が決まります 。

広告は表示だけでは課金されず、クリックされたときに費用が発生するクリック単価制です 。

つまり、今探している人に、今の意図に合う形で出せる広告です 。

## 広告ランク

掲載順位は入札額だけではなく、広告ランクで決まります 。

PDFでは、広告ランクは 入札単価 × 品質スコア と説明されています 。

また、実際のクリック単価は 自社直下の広告ランク ÷ 自社品質スコア + 1円 という式で示されていました 。

例では、C社は入札単価¥70でも品質スコア9で、広告ランク630、実際のクリック単価¥61となり、質が高いと少ない費用で上位を取れることが分かります 。

## 品質スコア

品質スコアは、推定クリック率・ランディングページの利便性・広告との関連性で決まります 。

推定クリック率は「その広告がどれくらいクリックされそうか」、LPの利便性は「クリック後のページが見やすく使いやすいか」、広告との関連性は「検索語と広告内容が合っているか」です 。

PDFでは、広告文に数字やメリットを入れること、LPをスマホで見やすくすること、検索キーワードと広告文・LPを一致させることが改善策として示されていました 。

## 5. 広告の種類と役割

デジタル広告6種類は、表示先と役割で整理すると分かりやすいです 。

- リスティング広告: 検索キーワードに反応し、顕在層に強い。
- ディスプレイ広告: 多数のWebサイトに表示され、認知拡大に向く。
- 動画広告: YouTubeなどの動画サイトに表示され、情報量が多い。
- SNS広告: FacebookやInstagramなどのSNS内に表示される。
- ネイティブ広告: ニュースサイトやポータルサイトに自然に挿入される。
- アフィリエイト広告: アフィリエイターが記事やサイトを作る成果報酬型広告。
PDFのポイントは、広告の種類を単独で覚えるのではなく、どの層に何を出すかで見ることでした 。

## 6. ユーザー層との対応

PDFでは、ユーザーを潜在層・準顕在層・顕在層・明確層に分けていました 。

潜在層は商品やサービスを知らず関心も薄い層で、動画広告・ディスプレイ広告・SNS広告が向きます 。

準顕在層はニーズはあるが検討していない層で、ディスプレイ広告・ネイティブ広告・SNS広告が合います 。

顕在層はニーズがあり比較検討中の層で、リスティング広告とアフィリエイト広告が効果的です 。

明確層は商品理解が深く、自社サイト訪問履歴もある層で、リピートや関係構築が重要です 。

## 7. 設計の要点

設計で一番大事なのは、検索キーワード・広告テキスト・LPを一致させることです 。

まずペルソナと軸キーワードを決め、意図の近い語をまとめて広告グループを作ります 。

そのうえで、検索意図に合う広告文を作り、着地先LPも同じ方向性にそろえます 。

PDFでは「小田原 海鮮丼 おすすめ」や「イベント企画会社 費用」のような、具体的で意図が明確な検索語が例として使われていました 。

## 8. 運用の注意点

運用では、出して終わりではなく、出してから改善することが重要です 。

見るべき指標は、表示回数、クリック数、費用、クリック率、検索語句、CVRです 。

無関係な検索語句は除外し、良い語句は伸ばし、広告文とLPのズレは修正します 。

中小企業では特に、入札額より品質が効くので、品質スコア改善を軽視すると費用対効果が落ちます 。

## 9. Google他メニュー

PDFでは、Google広告の検索広告だけでなく、Googleビデオ（YouTubeなど）も触れられていました 。

Googleは検索、YouTube、Googleマップ、Gmail、Androidなど複数サービスのデータを横断して扱えるのが強みです 。

そのため、検索連動型広告だけでなく、他のGoogle広告メニューも接点として理解しておく流れになっています 。

## 10. Yahoo!広告との違い

Yahoo!広告の検索広告も、基本は検索連動型のテキスト広告です 。

ただし、GoogleとYahoo!では、ユーザー層、掲載先、表示オプション、入稿規定、ターゲティングの細かさが異なります 。

PDFの流れでは、Google他メニューを見たあとにYahoo!広告との違いへ進む構成だったので、最後はGoogle単独ではなく、比較軸としてYahoo!も押さえるのが自然です 。



リスティング広告は顕在層に強く、仕組みはオークションと広告ランクで動き、成果は設計と運用の質で決まる

ということです 。

さらに、広告種類の全体像、ユーザー層ごとの使い分け、Googleの理念、品質スコア、LP、Yahoo!比較までつなげて理解することで、実務で使える形になります 。

中小企業向けに言い換えるなら、

「今探している人」に、検索意図に合う広告を、品質を上げながら出し続ける施策

です 。
