## 【情報収集手法】3C分析 10ステップ調査手順

マーケティング分析で最も重要な「実データを使った3C分析」の手順。
AIの学習データではなく、必ずリアルタイムの一次情報を収集することが原則。

```
Step1：与件を読む → 商材・ターゲット・CVポイントを確認
Step2：公式LP → 自社の定性・定量を取得（価格・成分・オファー・機能性表示）
         ⚠️ 価格改定がある場合はLPが正。与件資料の価格はStep2で必ず上書き確認
Step3：Amazon・楽天ランキング → 本当の競合を特定
         ⚠️ 3条件（同カテゴリ・通販EC中心・同ターゲット）を満たす会社のみ選定
Step4：競合LP・レビュー → スペック・強み・弱みを取得
         ★5を20件・★2〜3を20件読んで頻出ワードを抽出
         競合の弱みが自社の差別化根拠になる
Step5：Meta広告ライブラリ → クリエイティブの型を確認（件数・最古配信日・コピー文言）
Step6：Google広告確認 → 指定キーワードで検索→スクショ→文字起こし→目視確認
         ⚠️ AIの推測で補完しない。スクショが一次情報
Step7：業界紙・矢野経済 → 市場規模・トレンドを取得
         ⚠️ 有料記事は参考値扱い。無料で確認できた範囲と区別して記載
Step8：厚労省・総務省 → 顧客の定量データを取得（一次情報として最も信頼できる）
Step9：Amazon・X・楽天レビュー → 顧客の定性データを取得（購買動機・離脱理由・潜在ニーズ）
Step10：全データを3Cに当てはめ → USPを導出
```

## 【フレームワーク】マーケティング分析の体系

### デスクリサーチ vs フィールドリサーチ

| | デスクリサーチ | フィールドリサーチ |
|---|---|---|
| 概要 | インターネットで収集できるデータを集め分析 | インターネットでは収集できないデータを集め分析 |
| 手法 | インターネット検索・リサーチレポート・購買データ・アンケート | インタビュー・ユーザー分析（UGC）・フィールド調査 |
| 特徴 | 既存データを活用した仮説構築に向く | ユーザー起点でのデータ収集・整理に向く |

### 3C分析（Company・Customer・Competitor）

**Customer（顧客）**
- 今夜布団の中で考えている悩みの具体的な姿
- 悩みが解決されたとき顧客の人生がどう変わるか（より良い未来）
- 購買をためらわせている心理的障壁と、それを乗り越えるきっかけ
- 購買動機・継続理由：UGCから抽出（Amazon★5レビュー20件）
- 離脱理由・バリア：競合★2〜3レビュー20件から抽出

**Competitor（競合）**
- 実際に売れている競合：楽天デイリーランキング・Amazon ベストセラーで特定
- 競合LP・Meta広告・Google広告の訴求軸を確認
- 競合が満たせていない顧客の欲求のギャップを探す
- 「競合の弱みが自社の差別化根拠になる」視点で分析

**Company（自社）**
- 公式LP・IR資料・プレスリリースから定量データ取得
- UGCポジティブワード（★5）から強みを言語化
- 機能性表示・受賞歴・独自成分など差別化根拠を整理

### SWOT分析
| | プラス要因 | マイナス要因 |
|---|---|---|
| 内部要因 | 強み（Strengths） | 弱み（Weaknesses） |
| 外部要因 | 機会（Opportunities） | 脅威（Threats） |

### マーケティングミックス（4P）
- **Product**：ブランド・品質・デザイン・機能
- **Price**：割引・値下げ・バンドリング
- **Place**：店舗・オンライン・配送
- **Promotion**：広告・キャンペーン

### STP分析
- **Segmentation**：市場を欲求・悩みの深さで分ける
- **Targeting**：最も変化を届けられるセグメントを選ぶ
- **Positioning**：競合が占めていない独自のポジションを取る

### カスタマージャーニー（4フェーズ）
| フェーズ | 認知 | 興味・関心 | 検討・比較 | 購入 |
|---|---|---|---|---|
| タッチポイント | 広告・SNS・口コミ | 検索・レビュー・紹介 | 比較・評価・相談 | 購入・契約・利用 |
| 思考・感情 | 問題認識・関心 | 情報収集・評価 | 比較・検討・不安 | 満足・期待 |

### バリュープロポジション（ベン図の3要素）
1. 価値が顧客に伝わっている状態
2. 競合と比較できる状態
3. その組み合わせが競合には実現できない状態

## 【市場調査の情報源リスト】

### 定量データ（市場規模・統計）
| 情報 | 調査先 | 調べ方 |
|---|---|---|
| 市場規模・トレンド | 矢野経済研究所プレスリリース | Google「[業種] 市場規模 矢野経済 [年]」 |
| 業種別売上・業況 | 業界紙（健康産業新聞など） | Google「[業種] 市場規模 [年] 業界紙」 |
| 顧客定量データ | 厚労省「国民健康・栄養調査」 | Google「厚生労働省 [指標] 令和[X]年」 |
| 人口動態 | 総務省「国勢調査」 | Google「総務省 人口 統計 [年]」 |
| 検索トレンド | Google Trends | trends.google.co.jpで5年間グラフを確認 |
| 企業業績 | IR資料・決算資料 | Google「[社名] 決算 [年]」 |

### 定性データ（顧客の声・競合情報）
| 情報 | 調査先 | 調べ方 |
|---|---|---|
| 競合特定 | Amazon・楽天ランキング | 「Amazon [商品カテゴリ] ベストセラー」 |
| 顧客の購買動機 | Amazon★5レビュー | 商品検索→レビュー欄★5を20件読む |
| 顧客の離脱理由 | Amazon★2〜3レビュー | 同上★2〜3を20件読む |
| SNS口コミ・潜在ニーズ | X（旧Twitter）・Instagram | 「[商品名] 飲んでみた」「[業種] 体験」 |
| 競合広告（SNS） | Meta広告ライブラリ | facebook.com/ads/libraryで企業名検索 |
| 競合広告（検索） | Google広告 | 対象キーワードで検索→スポンサー枠を確認 |
| 競合LP | 競合公式サイト | 直接URLを確認 |

## 【マーケティングの思想的基盤】

### Eugene Schwartz「欲求は商品より先に存在する」
顧客はすでに欲求を持っている。仕事は欲求を「作る」ことではなく「発掘し、商品と繋げる」こと。
顧客が今夜布団の中で考えていること、朝起きて最初に感じる不安、解決できたら人生がどう変わるか。
この「顧客の内側にある物語」を出発点にしない分析は、どれだけ整理されていても意味がない。

### ロイヤリティステージ思考
顧客との関係には深さのステージがある：
**知ってる → いいね！ → 役立つ → 好き！ → 信頼 → 欠かせない**
広告・販促が届かせられるのは「役立つ」まで。「好き・信頼・欠かせない」は直接的な体験と対話によってのみ生まれる。

### 競合分析の本質
競合分析は「競合が強い・弱い」の評価ではなく「競合が満たせていない顧客の欲求のギャップ」を探す作業。
競合のレビュー（★5の感動と★2〜3の不満）の中に、このビジネスが入り込める差別化根拠が眠っている。

### PDCAサイクル
1. **Plan（計画）**：目標設定・課題特定・計画立案
2. **Do（実行）**：計画の実施・データ収集
3. **Check（評価）**：結果の分析・課題の特定
4. **Act（アクション）**：改善の実施・フィードバック

## 【広告クリエイティブ3類型（実例）】

| 類型 | 代表的訴求 | 向いている状況 |

## 【Growlの実践知見：小規模事業者のマーケティング原則】

1. **「何を投稿しよう」問題の解決法**：3C分析で競合の弱みを特定→そのギャップを埋めるコンテンツを投稿
2. **スマホ1台・30分以内で完結**：Instagram/LINE/Googleマップなど既存プラットフォームを活用
3. **週3アクション**：毎週3つの具体的な施策に絞ることで継続率が上がる
4. **業種別の主戦場チャネル**：
   - 飲食店：Instagram（映え）+ Googleマップ（口コミ）
   - 美容サロン：Instagram（ビフォーアフター）+ LINE（リピート）
   - EC・通販：Amazon/楽天ランキング + SNS + Meta広告
   - 士業・コンサル：SEO + LinkedIn/X + メルマガ
   - 工務店：Googleマップ + チラシ + 施工事例ブログ
5. **定量データ必須**：「多い」「人気がある」はNG。必ず「〜万人・〜%・〜億円」に変換
