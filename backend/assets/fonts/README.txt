# フォントディレクトリ

日本語フォントをここに配置してください。

## 推奨フォント: IPAexゴシック (ipaexg.ttf)

1. https://moji.or.jp/ipafont/ からダウンロード
2. または: https://github.com/jlongster/extender/raw/master/data/ipaexg.ttf

ダウンロード後、このフォルダに `ipaexg.ttf` という名前で保存してください。

## フォントが見つからない場合
Windows環境では以下のシステムフォントを自動的に使用します:
- Yu Gothic (YuGothM.ttc / YuGothB.ttc)
- Meiryo (meiryo.ttc)
- MS Gothic (msgothic.ttc)

いずれも見つからない場合は文字化けが発生する可能性があります。
