# 路上キャッチで学んだ、人の心を引く瞬間

結論から言うと、人が足を止める瞬間の法則は、ただのコツではなかった。
私は18歳の頃、カラオケ店の路上キャッチをしていた。
当時は、18〜24時までの6時間、平日は10組、休日は10〜15組を必死に捌いていた。
声をかけても9割無視される中で、接客と集客の原体験を積んだ。
その時の経験が、今のマーケティングの仕事に大きな影響を与えている。

当時の現場の状況は、かなりタフだった。
客の9割が無視する中で、1割の客をどうやって引き付けるかが課題だった。
私は、ただ声をかけるだけではだめだと気付いた。
そのため、客のニーズを理解し、客の心を引くためのテクニックを勉強した。

その中で出会ったのが、AIDAという購買行動モデルだった。
Attention、Interest、Desire、Actionの頭文字を取ったもので、
人の心を引くためのプロセスを表している。
ただ、当時は、ただの理論だった。
実際に客を引き付けるには、もっと具体的なテクニックが必要だった。

そこで私は、実際の客引きで学んだテクニックを、AIDAの各ステップに当てはめてみた。
まず、Attentionのステップでは、
客の目につくような服装やアクセサリーを着用することで、
客の注意を引くことができた。
次に、Interestのステップでは、
客のニーズを理解し、客の興味を刺激するような話題を提供することで、
客の興味を引くことができた。

Desireのステップでは、
客の欲求を理解し、客の欲求を満たすようなサービスを提供することで、
客の欲求を満たすことができた。
最後に、Actionのステップでは、
客の行動を促すために、
具体的なアクションを促すような言葉遣いやジェスチャーを使用することで、
客の行動を促すことができた。

その結果、客の引き付け率が大幅に上昇した。
私は、ただのコツではなかったことを実感した。
人の心を引く瞬間の法則は、
ただのテクニックではなかった。

今のマーケティングの仕事でも、
この法則を利用して、
顧客の心を引くために努力している。
ただ、まだまだ学ぶことがある。
人が足を止める瞬間の法則は、
一人ひとりの経験から学ぶことができる。

まずは、自分の経験から学んでみてください。
人を引くためのテクニックを、
AIDAの各ステップに当てはめてみてください。
その結果、
人の心を引く瞬間の法則が、
わかり始めるはずです。
