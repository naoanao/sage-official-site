# バーガー屋で売上が落ちたとき、競合・顧客・自社を並べた話　3C分析という考え方

売上が落ち始めた頃、私はバーガーを焼いていた。

2008年。Uncle Samを始めて2年目。

最初は順調だった。でも**ある時期から、客足が鈍くなった。**

平日の昼は来る。夕方が弱い。土日は悪くないのに、翌週の月曜に急に落ちる。

「景気のせいかな」と最初は思っていた。今思えば、それが一番まずかった。原因を外に求めると、何も変わらない。

あるとき、近くに大手チェーンが出店した。価格は私より安い。メニューも多い。席数も多い。

正直、焦った。「勝てるのか」と思った。

でも焦っているだけでは何も見えない。だから初めて、ノートに書き出してみた。

**「誰が来ているか」「競合は何をしているか」「自分たちは何者か」**

この3つだけ。

「誰が来ているか」を丁寧に見ると、常連客に偏りがあることに気づいた。

近所の個人事業主と、昼休みの会社員と、週末の家族連れ。この3グループが売上の大半を占めていた。

それぞれ、来る理由が違う。個人事業主の方は「話しながら食べられる場所」が欲しかった。会社員は「早く出てきて、少し落ち着ける」を求めていた。家族連れは「子どもが騒いでも怒られない空間」を探していた。

全員に同じ接客をしていた。これが間違いだった。

「競合は何をしているか」を見ると、大手は**「速さ・安さ・均一さ」**で戦っていた。

同じ土俵で戦っても勝てない。資本が違いすぎる。

そこで「自分たちは何者か」を正直に書いてみた。一つだけ、大手にないものがあった。

**バーの接客スタイル。**

私はもともとバーで働いていた。お客さんの顔を覚えて、好みを覚えて、その日の気分に合わせて一言添える。バーガー屋でそれをやると、「ここに来ると落ち着く」と言ってくれる常連が増えた。

これが、自分たちの強みだった。

後になって、**3C分析という考え方**に出会った。Customer（顧客）・Competitor（競合）・Company（自社）の3つを並べて、「どこで戦うか」を整理するフレームワークだ。

大手と同じ土俵に乗らない。「バーの接客をするバーガー屋」という軸で、個人事業主と家族連れに絞って動き直した。

客数は大きく増えなかった。でも**リピート率が上がった。**売上の波が、少し穏やかになった。

市場を「競合が来た」と見るだけでは何も変わらない。「自分たちが誰に・何で勝てるか」を整理したとき、初めて次の手が見える。

それだけだった。
