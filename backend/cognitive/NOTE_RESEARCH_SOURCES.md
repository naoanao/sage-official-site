## ▌ SECTION 5 — 文体法則（verified版）

### 高スキ記事から抽出した共通パターン

```
1. 1文1行スタイル（特に短文）
   例: 「諦めました。」「0円でした。」「始めました。」

2. 失敗・諦め・挫折を先に置く
   例: murata_ssj記事冒頭: 「考えていた時期が俺にもありました」

3. 「学んでいます」禁止 → 「やってみたらこうだった」に変換
   悪い例: 「マーケを勉強しています」
   良い例: 「STPをバーガー屋に当てはめたら、ターゲットが間違ってた」

4. スキ率 > スキ数 （noteのアルゴリズム）
   → 少数でも「共感した」人が多い記事が伸びる
   → 広い読者ではなく「なおさんの話だ」と感じる読者を狙う

5. 理想文字数: 1500〜2500字（watamari実データより）
   → 800〜1000字のSTORY_BIBLE推奨より少し長め（修正余地あり）

6. 継続カウンター（Day X）は信頼の証
   → murata_ssj「365日連続投稿達成」= プロフィールに記載するだけでスキが増える
```
