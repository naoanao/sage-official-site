2. 機能は足りているのに、流通が製品に内蔵されていない
3. 価格戦略が弱い（競合の半分〜1/5）

## 収益化の3段階

### Phase 1: 値上げ（コード変更のみ、今すぐ）

**現在:** Free / $19 / $49
**新価格:** Free / **$29** / **$79**

値上げの根拠:
- 競合最安値のBufferは$19（スケジューリングのみ）
- Growlは生成＋診断＋分析＋スケジューリングを提供
- $29でも競合の30-50%安い

同時にFreeの制限を強化:
- 5分析/月（現状維持）
- LearnAIは基礎のみ
- 診断結果は無料だが、完全改善プランは有料化

## 機能クロスオーバーによる新しい収益化アイデア

### ① Sage Scholar + Productize = 自動マーケットレポート販売
- Sage Scholarで業界論文を自動収集
- Productizeでレポート化
- Whop/Gumroadで$19-29で販売
- 月1本 × 10業種 = 月10本のデジタル商品

### ② 診断 + PDF生成 = ダウンロード診断レポート
- 診断結果をPDF化
- メールアドレス必須（リード獲得）
- 無料PDFでリードを集め、有料プランに誘導

### ③ Sage Bluesky自動投稿 + Growl = 自動販売サイクル
- Sageが毎朝BlueskyにGrowlのPRを投稿
- Growlが診断で獲得したユーザーを有料化
- 有料ユーザーの投稿をSageが自動化
- SageがさらにPR投稿 → ループ完成

### ④ EngagementBot + Content Pool = 自動返信システム
- EngagementBotを再開（返信ペルソナ修正後）
- コメントに自動返信し、診断ツールへのリンクを含める
- 1日数件の自然な対話から流入獲得

### ⑤ LearnAI + 診断 = 無料→有料の教育導線
- 診断 → 「なぜこのスコアなのか」 → LearnAIで学習 → 有料ツールで実践
- 教育コンテンツが無料のマグネットになる
