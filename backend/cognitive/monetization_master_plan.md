## コア問題

**Growlの有料プランが安すぎる上に、無料で使いすぎ。**

月$19で「無制限」を出すと、$19払ったユーザーが全機能を使い放題になる一方、無料ユーザーに5世代/月（分析+全フレームワーク+LearnAI+診断+Meta広告生成）を与えている。

星野ロミのビジネスと比較すると根本的に違う:

| 星野ロミ（Social XP） | Sage / Growl |
|---------------------|-------------|
| 1機能（診断）だけを無料公開 | 20+機能を無料公開 |
| 広告収入で収益化（無料でもOK） | 月額課金のみで収益化 |
| 流通=製品に内蔵（診断結果をXシェア） | 流通=手動で売りに行く |
| ユーザー0人から$0でスタート | 収益化インフラだけで1年かかった |

**結論: 機能は十分すぎる。足りないのは流通と課金設計。**

## 収益化プラン（3段階）

### Phase 1: 値上げと機能ゲート（今日できる、コード変更のみ）

現在のFree/Standard/Proの価値を再定義する。

**新しい課金設計:**

| プラン | 価格 | 価値の核 |
|-------|------|---------|
| **Free** | $0 | 診断クイズ（無制限）+ フレームワーク分析1回/月 + 診断結果の1個の改善アクション |
| **Standard** | **$29/mo**（$19→値上げ） | 全フレームワーク分析 無制限 + 週次アクション3つ + 診断の完全な改善プラン + Meta広告生成 |
| **Pro** | **$79/mo**（$49→値上げ） | Standard全機能 + SNS自動投稿 + 動画生成 + 商品生成パイプライン + 優先サポート |
| **Blueprint** | $49 買切 | 従来通り変更なし |

**なぜ値上げできるか:** 競合（Typeform $39、Buffer $19-99、Synthesia $30-100）と比較して、Growl Pro $79でも十分安い。
