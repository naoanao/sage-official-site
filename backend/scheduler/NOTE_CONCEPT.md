## 2. 高評価記事の共通パターン（法則）

### 文体・構造
1. **極めて短い文** — 1文1行が基本。「飛び起きた。」「届いた。」「0円だった。」
2. **感情の変化を追う** — 怖い→動いた→届いた→嬉しかった、という弧
3. **失敗・弱点を最初に書く** — 「稼ぎは0円」「怖かった」「挫折した」から入る
4. **正直なデータ開示** — スキ数・フォロワー・収益（小さくても正直に）
5. **シリーズ化** — vol.XX方式、継続読者を作る仕組み

### キャラクター設計
6. **独自のアイデンティティ** — 「挫折王」「元病院事務」「40代アラフォー」
7. **「普通の人でもできる」感** — 高実績よりも「続けた人」を見せる
8. **人格が見える余談・日常** — 生活感・雑談で親近感を出す

### 構成・CTA
9. **具体的な数字を毎回入れる** — 何日目、スキ何件、売上何円
10. **末尾にスキ・フォロー依頼** — 「よかったらスキお願いします」は必須
11. **タグを20〜50個** — 集客の要

## 4. Sage note.com の確定コンセプト

### タイトル：「バーガー屋がAI自動化で年収1000万を目指す日記」

### キャラクター設定
- 名前：なお
- 属性：神奈川・バーガーショップ店主・AI開発ソロデベロッパー・Day X
- トーン：砕けた語り口、正直、人間臭い
- 禁止：「〜を学んでいます」「革命的」「ゲームチェンジャー」「抽象論」

### 記事スタイル（高評価パターンを採用）
- **極短文体**（1文1行）— 「今日もバーガーを焼いた。」「Sageが動いた。」
- **感情実況** — 怖かった、嬉しかった、想定外だった
- **実況日記** — その日起きたこと・作ったもの・気づき
- **正直な数字開示** — フォロワー数、Gumroad売上、スキ数（たとえ0でも）
- **失敗も書く** — うまくいかなかったことを隠さない
- **バーガー屋視点** — 「仕込みの合間に」「お昼のピーク後に」という生活感

### 記事構成（テンプレート）
```
1. タイトル：Day XX. ＋ 今日の一言（具体的）
2. 書き出し：今日の状況を1-2文で
3. 本文：
   - 今日やったこと（具体的）
   - 数字・データ（正直に）
   - 失敗or気づき
   - バーガー屋との絡み（生活感）
   - AIマーケ知識1つ（STP・3C・AISAS等から実践的に）
4. 締め：
   - 明日の予定 or 読者へのメッセージ
   - Gumroad CTA（自然に）
5. タグ（20〜30個）
```

### 文字数
- 800〜1200字 — 読みやすさ最優先（長すぎない）

### 毎回入れる要素
- Day番号（Day 353 など）
- スキ/フォロワー現在値（あれば）
- Gumroad URL：https://naofumi3.gumroad.com/l/apvbzh
