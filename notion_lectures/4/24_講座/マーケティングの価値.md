# マーケティングの価値

マーケティングとは一言で言うと、「売れる仕組みを作り、買い続けてもらう仕組みを作ること」です。この講義では、なぜ「価値」がマーケティングの中心にあるのかを体系的に解説しています。
1. マーケティングの2大戦略
マーケティングは「プロダクト戦略」と「プロモーション戦略」の2軸で構成されます。
戦略
	
要素
	
内容


プロダクト戦略
	
MR（マーケットリサーチ）

プロモーション戦略
	
VP（バリュープロポジション）
	
顧客が喜ぶ価値を見つけ、提供する


	
MP（マーケティングプラン）
	
価値の重要さを伝える仕組みを作る
2. マーケティングの本質は「価値の提供」
顧客が喜ぶことを、顧客が求めるタイミングで提供できると、買ってくれる。
マーケティングの核心は、顧客へ価値を届けることです。商品・サービスをただ「売る」のではなく、次の3ステップを意識します。
売ってくれた（一方的な販売）← マーケティングではない
買い替えてくれた（顧客の自発的な再購入）← 価値提供の証拠
売れる仕組みを作った ← 本当のマーケティング
3. なぜ「買い続けてもらう」ことが必要か？
1回の購入だけでは倒産してしまうからです。
新規顧客を獲得するには広告費（CPA）がかかるため、初回購入時は赤字になることがほとんどです。
text初回購入 → 赤字（広告費・コストが回収できない）
2回目購入 → 損益分岐点に到達
3回目購入 → 投資回収成功 ​
つまり、顧客1人あたりの利益を最大化するには、3回以上購入してもらうことが目標になります。このグラフを意識せずに「1回売れた！」で満足しているビジネスは、構造的に成立していません。
4. 顧客との関係を「育てる」視点
顧客は段階を経てロイヤル化していきます。
ユーザーの段階（顧客ステージ）:
text見込み客 → 顧客 → 得意客 → ロイヤルユーザー
顧客の行動フロー:
text認知 → 興味関心 → 検討 → 購買 → 利用 → リピート → 口コミ → 推奨
マーケティングの仕事は、この流れを設計し、「見込み客をロイヤルユーザーへと育てる仕組み」を作ることです。
5. CRM（顧客関係管理）が重要な理由
CRM（Customer Relationship Management / 顧客関係管理）とは、顧客と長期的な関係を構築し、リピート率とロイヤルティを高め、収益を最大化させる考え方・仕組みです。
CRMを実現するための2つの柱：
VP（バリュープロポジション）：顧客に「買い続けたい」と思ってもらえる価値を設計する
MP（マーケティングプラン）：その価値を「伝える仕組み」を作る
6. まとめ｜マーケティングの定義
「お金と価値の交換を通じて、顧客との関係を作っていくこと」
それがマーケティングの本質です。
 売れるものを作り（プロダクト戦略）
 価値を伝え（プロモーション戦略）
 顧客に3回以上買い続けてもらい（LTV最大化）
 ロイヤルユーザーを育てる（CRM）
この一連の流れを仕組み化したものが、本質的なマーケティングです。1回売れることではなく、「買い続けてもらう設計」こそがビジネスの生命線であることを、この講義は繰り返し強調しています。
バリュー・プロポジション（Value Proposition）要点まとめ
核心：顧客はなぜ買うのか
顧客が商品を購入するのは「商品そのもの」が欲しいのではなく、何らかのジョブ（用事・タスク）を片付けるために商品を「雇用」している。ジョブをうまく解決できれば、同じジョブが発生したとき同じ商品を再び選ぶ＝リピート購入につながる。
例：ドリルを買う理由は「穴の空いた板が欲しい」から。ドリルそのものが欲しいわけではない。
価値提案の2軸：GainsとPains
顧客のジョブに対して、提供できる価値は2種類ある。
軸
	
意味
	
自社の対応策


Gains（得られるもの）
	
ジョブを解決した結果、顧客が得る満足・喜び
	
Gain Creators（利益をもたらす機能・提案）


Pains（悩み・障害）
	
ジョブを解決する過程で顧客が抱える不満・面倒
	
Pain Relievers（悩みを取り除く解決策）
同じニーズでもジョブが違えば価値提案も変わる
表面的なニーズ（例：「掃除手段が欲しい」）は同じでも、その裏にあるジョブと動機が異なれば、刺さる商品・価値提案は全く変わる。
Aタイプ：「部屋を徹底的にキレイにしたい」→ コードレス掃除機が最適（パワフルな吸引力・達成感・自分で実感したい）
Bタイプ：「手間をかけずキレイな部屋で暮らしたい」→ ロボット掃除機が最適（自動化・IoT・留守中に完了）
ジョブ別・価値提案の具体例
コードレス掃除機（自分で掃除したい層）
Gains：パワフルな吸引力、空気も清潔に、達成感
Pain Relievers：コードレスで身軽、ゴミ捨て簡単、60分連続使用、2年保証＋サポート
ロボット掃除機（手間を省きたい層）
Gains：いない間に掃除完了、毎日清潔を維持
Pain Relievers：ボタン一つで稼働、自動充電、アプリで掃除マップ確認、5万円以下で購入可能
まとめ：VPを設計する3ステップ
顧客のジョブを特定する（表面のニーズを分解して本質を探る）
Gains／Painsを整理する（何を得たいか・何に困っているか）
Gain Creators／Pain Relieversを設計する（ジョブに合わせた価値提案を行う）
同じ商品でも「誰のどのジョブ向けか」を明確にすることで、顧客が買い続ける理由になる。
価値の伝え方とブランド構築 要点まとめ
1. 嘘はバレる：フレーミング効果と文脈効果
マーケターが虚偽や誇大な表現をしてもすぐに調べられる時代。ただし見せ方・伝え方は合法的に活用できる。
フレーミング効果：「タウリン1g」と「タウリン1000mg」は同じ量だが、数字の大きい方が多く感じられる
文脈効果：メニューに「特上30,000円」があることで「松20,000円」が割安に見える
事実は変えなくても、枠組みと文脈で受け取り方は変わる。

3. マーケターの本当の役割
マーケターは「売る」のではなく**「買いたそうな人に買ってもらう後押し」**をする存在。
Loyalty Loop（顧客ロイヤリティの循環）
text認知・検討 → 購入 → 体験・評価 → 口コミ（Other）→ 新たな顧客の検討へ
                           ↑
                     ここを磨くことが最重要
マーケターがすべきこと：
後押し：買いたそうな人に適切にリーチ
体験の向上：満足度を上げてリピートと口コミを生む
顧客の関与を高める：ブランドとの関係性を深める

まとめ：価値伝達の核心
企業が伝えたいことを発信するだけでは不十分。顧客が体験し、口コミを生み、ブランドイメージを形成する——このループを設計することがマーケターの本質的な仕事。
