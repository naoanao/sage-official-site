# 企画書の作成

## 「良い企画」は「選ばれた企画」である

どんなに完成度が高い企画書でも、相手に納得してもらえなければ意味がゼロです。企画の良し悪しは、内容の質だけでなく「相手を動かせたかどうか」で決まります。

企画を通すために必要な力の配分はこうです。

text相手の理解（誰に何を提案するかを把握）  ……40%
論理的なストーリー（納得できる流れ）    ……40%
プレゼン技術（伝え方・見せ方）          ……20%

> デザインが綺麗な企画書 ≠ 良い企画書。 図解・ビジュアル多用・コンセプト不在の企画書は見た目だけで中身がない。目的は「相手を納得させること」ただ一点。

## ① 相手を理解する

提案前に必ず確認すべき「相手の構造」があります。

社内提案の場合は上司・部門責任者が相手になり、対外提案の場合は担当者・決裁者・周辺関係者の構造を把握する必要があります。提案の相手と決裁者が同一でないケースでは、担当者の「ゴール（セミナー集客・資料請求・良質顧客確保・自社製品の拡販）」と、決裁者の「ゴール」が異なる場合があるため、両方を意識したストーリー設計が必要です。

## ② 納得させるストーリーの8ステップ

企画書の構成は「なぜこの提案が必要か」から「いくら必要か」まで、迷子にならない順番で進めます。

text1. 背景・課題      ← なぜ今これが必要なのか？
2. 現状分析        ← 今どんな状態か？（数値・データで示す）
3. 課題（改善点）  ← 何が問題か？
4. コンセプト      ← ターゲットと戦略の方向性
5. 全体概要        ← 施策の全体像
6. 具体的施策      ← 何をどうやるか？
7. 目標・KPI       ← どうなれば成功か？
8. 必要予算        ← いくらかかるか？

## ③ 納得させる技術：2つの武器

## 武器①：数値エビデンス

アイデアだけでは人は動きません。数値データが「なぜこの施策が必要か」を代わりに語ってくれます。

収集すべきデータの例：

- 登録者数・CV数推移・SNS流入・広告効果測定
- 売上・市場規模・アクセス解析・問い合わせ数・顧客購買データ
数値の活用例（CV率改善のインパクト計算）：

→「CV率を1%上げましょう」より「CV率を1%改善すると年間で○○億円の売上インパクトがあります」という見せ方をすることで、相手の意思決定が劇的に速まります。

## 武器②：競合比較

自社の課題を「自分たちだけの問題」として語るより、「競合他社はこうやっている」と横並びで見せると説得力が上がります。

比較する項目の例（WebサイトやSNS運用の場合）：

- Webサイトのデザイン・構成・キャッチコピー・メインバナー・サイドメニュー
- 自然検索順位・フォーム・CRM状況
- SNS運用状況（TikTok・Instagram・Xなど各社の活用有無）
- プロモーション手法（SEO / リスティング / リターゲティング / コンテンツマーケティングなど）
## Webプロモーションの全体構造

Webで売上を上げるための施策は、以下の3ステップで考えます。順番が重要です。

text① Web集客（ROI改善）
    → まずユーザーを連れてくる
         ↓
② Web接客（CV改善）
    → 来たユーザーを購入・問い合わせに転換する
         ↓
③ リピート促進（CRM施策）
    → 一度買ってくれた人にまた買ってもらう

## ポイント①：ペルソナをベースに施策を選ぶ

「この年齢・職業・関心を持つ人（ペルソナ）はどのメディアに接触しているか？」を起点に施策を決めます。ペルソナ設定なしで施策を選ぶのは、誰に向けて話しているかわからない状態でプレゼンをするようなものです。

## ポイント②：競合他社がやっていることをベースに選ぶ

業界で売上を上げている企業が実施している施策は、「それが効く」という証明がすでにされています。競合が使っているメディアや施策を分析し、それを根拠として提案に組み込むことで説得力が上がります。

## Web接客（CV改善）：ユーザビリティの重要性

Web接客とは、サイトに来たユーザーを購入・問い合わせ・資料請求に誘導することです。その鍵はユーザビリティ（使いやすさ）です。ヤコブ・ニールセンの定義によれば、「欲しい情報に迷わずたどり着けるサイト」がCV率を高めます。

## 企業背景の把握（例）

- 最後のサイトリニューアルから3年以上経過
- CMSがなく情報更新が遅い（セミナー告知が間に合わないケースが発生）
- モバイルファーストインデックスへの対応が未対応
- アクセス数が低迷している

## 競合分析の視点（Webサイト比較で見る項目）

- トップイメージ・キャッチコピー・電話番号表記の位置
- 無料サンプル・資料請求ボタンの有無と掲載数
- グローバルメニュー・サイドメニューの構成
- SNS誘導バナー・キャンペーン一覧・メインバナーの内容
## 予算・KPI設定の作法

- なるべく予算の範囲内に収め、超過分はオプション扱いで明示
- 社内リソース（人的工数）を使う場合は明確にコスト換算する
- どの部分にいくらかかるかを項目別に詳細に出す
- KPIは「月間○本コンテンツ増加 → ○ヶ月後に月間UU数○○達成」のように、過去データを根拠にした具体的な数値で設定する
## 全体のポイント：3行まとめ

text1. 相手（担当者・決裁者）が何を求めているかを先に理解する
2. 背景→課題→施策→KPI→予算の順番でストーリーを組む
3. 数値データと競合比較で「主観」を「根拠」に変える
